# Use Brian artwork

`Brian.icns` is the existing Use Brian application icon, copied from the installed
Use Brian app. `mascot-reference.png` is the existing cyan pixel mascot from
`brian-platform/use-brian/assets/mascot.png`.

The desktop companion in `BrianCompanion.swift` reproduces that pixel silhouette
with native drawing, adding blinking eyes, idle motion, working footsteps and a
success expression. It respects macOS Reduce Motion. No generated replacement
brand artwork is used.
